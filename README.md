# Bosco Peluqueros — web

Web estática (HTML + CSS, sin dependencias). Abre `index.html` en el navegador para verla.

## Qué hay que rellenar
Busca `EDITAR` en `index.html`:

- `BOOKSY_URL` → enlace del perfil de Booksy (aparece 4 veces)
- `34600000000` → número de WhatsApp con prefijo 34, sin espacios (y el `600 00 00 00` visible)
- Precios, horario, dirección e Instagram
- Fotos: guárdalas en `img/` y cambia los bloques `<div class="ph">` por `<img src="img/...">`
- En el mapa, cambia `q=Bosco%20Peluqueros` por la dirección exacta

## Publicar gratis
GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
